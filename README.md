# PostSnag

Analyse the Facebook content you captured with the PostSnag Chrome extension, from a conversation with Claude.

## Use it

Connect the PostSnag connector from this plugin's **Connectors** tab and sign in with your PostSnag account (Pro or Lifetime). Then ask in plain words, for example "analyze my Facebook hooks for Jane Doe", "when should this profile post?" or "what works in my gardening group?". Claude picks the matching skill and reads the posts from your PostSnag library. Without the connector, the skills still run on a PostSnag CSV or Markdown export you attach, or on posts you paste.

Skills: facebook-hook-analyzer, best-time-to-post-reader, facebook-profile-audit, facebook-group-post-analyzer, competitor-content-gap-finder, evergreen-repost-finder, facebook-caption-writer, creator-voice-skill-builder, facebook-content-calendar-builder, viral-post-teardown, capture-target-builder.

## Data

The connector reads the posts, profiles, groups and comments you saved in PostSnag through the PostSnag API. It never posts to Facebook or scrapes it. The skills themselves send nothing anywhere.
